# Protocol engravings

Sage steel-engraving illustrations for the Longevity and Menopause Protocol pages on beoptimal.ca, in the IV iron page's house style.

- **[HANDOFF.md](HANDOFF.md)**: the handoff for engineering. It covers what goes where, the captions and alt text, the CSS and markup, the steps for each page, QA, and what Peter must sign off.
- **[manifest.json](manifest.json)**: one entry per image, with its placement, caption, alt text, prompt, Higgsfield job id, master URL and hosted web files.
- **[process.py](process.py)**: rebuilds the web files, or makes print files, from the masters.

The images are hosted on Higgsfield, not in this repo. The zip link is at the top of HANDOFF.md.
