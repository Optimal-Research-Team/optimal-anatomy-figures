# Optimal brand, as it applies to the figures

The token map for the Anatomy kit is **`shared/optimal-theme.css`**. These are the source values.

| Role | Value | Source |
|---|---|---|
| Page / card (cream) | `#FEF8F1` / `#FFFCF7` | site `--background`, `--ow-100` |
| Bone (volumes) | `#E7E2D9`, `#F0EDE5` | ALE visualizer spec |
| Ink strong / body / muted | `#252525` / `#3E3D39` / `#76736D` | ALE spec, Performance one-pager |
| Forest (the one lit accent) | `#2C4E25` | site `--new-accent` |
| Forest light | `#519044` | site `--new-accent-light` |
| Sage (eyebrows, numbering) | `#5E7A59` | Performance one-pager |
| Light green wash | `#E2EDDF` | site `--lgreen` |
| Borderline / out of range | `#C97B2D` / `#B3402F` | ALE spec (state colours) |
| Warm accent (heat) | `#FF9776` | site `--accent` |
| Forest night / forest hero (dark) | `#1C3118` / `#253821` | ALE spec, exam-room TV theme |

**Type:** **Castoro** (display serif: titles, numbering, italics for emphasis) and **Public Sans** (UI, body, readouts with tabular numbers). Load both from Google Fonts: `family=Castoro:ital@0;1&family=Public+Sans:wght@400;500;600;700`.

**Voice:** plain, warm, specific. Example from the site: "See how you *really* run." Short sentences. One italic word for emphasis in a headline. Never alarmist, never "biohacker".
